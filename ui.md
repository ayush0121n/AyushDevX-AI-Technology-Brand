# AyushDevX — UI/UX Design System

---

## 1. Design Direction

The AyushDevX interface should feel like a premium AI technology company.

**Visual characteristics:**
- Futuristic
- Minimal
- Professional
- Elegant
- Technical
- Premium
- Clean

The design should be suitable for:
- Recruiters
- Developers
- Founders
- Clients
- Technology enthusiasts

---

## 2. Brand Personality

The visual identity should communicate:
- Intelligence
- Innovation
- Engineering
- Reliability
- Creativity
- Future-focused thinking

---

## 3. Color System

Use a modern dark-first design.

**Background:** Deep dark background
**Surfaces:** Elevated dark surfaces
**Accent:** One primary AI-inspired accent color

Use gradients sparingly.

Do not use too many colors.

The accent color should be consistent throughout:
- Buttons
- Links
- Active navigation
- AI Lab highlights
- Interactive elements

Support light mode.

---

## 4. Typography

Use a modern sans-serif font.

**Typography hierarchy:**

| Level | Usage                          |
|-------|--------------------------------|
| H1    | Large, bold, highly readable   |
| H2    | Strong section headings        |
| H3    | Card and feature titles        |
| Body  | Comfortable reading size       |
| Small | Metadata and supporting info   |

Avoid excessive font sizes.

---

## 5. Navigation

**Desktop:**

```
AYUSHDEVX    Home  AI Lab  Products  Projects  Knowledge Hub  Insights  About  Contact    [Theme]
```

**Mobile:**
Use a clean hamburger menu.

Navigation should remain accessible.

---

## 6. Hero

Hero should be visually strong.

**Structure:**
1. Brand label
2. Large headline
3. Supporting description
4. Primary CTA
5. Secondary CTA
6. Visual AI element

**Suggested visual:**
- Abstract AI network
- Data visualization
- Digital intelligence graphic

Do not use generic stock photos.

---

## 7. AI Lab UI

The AI Lab should feel like a real application dashboard.

**Use:**
- Tool cards
- Status indicators
- AI icons
- Interactive demos
- Input areas
- Results panels

**Each AI tool should have:**
```
Header
Description
Input
Processing state
Output
Actions
```

---

## 8. AI Chat UI

**Chat layout:**

```
[Optional History] | [Conversation] | [Input Bar]
```

**Message actions:**
- Copy
- Regenerate
- Clear

**For RAG — show:**
- Source
- Page
- Document

Use expandable source citations.

---

## 9. Knowledge Hub

**Layout:**
```
[Search Bar]
[Category Filters]
[Resource Cards Grid]
```

**Resource card:**
- Thumbnail
- Title
- Description
- Category
- Tags
- Date
- Preview button
- Download button

---

## 10. Project Cards

**Each project card:**
- Project image
- Project title
- Short description
- Technology tags
- Live Demo button
- GitHub button
- Case Study button

Use hover animation.

Keep animations subtle.

---

## 11. Product Cards

Product cards should look more polished than project cards.

**Include:**
- Product icon
- Product name
- Short description
- Features list
- Try Now button

---

## 12. Blog / Insights UI

**Article card:**
- Image
- Category
- Title
- Excerpt
- Date
- Reading time
- Read Article link

**Article page:**
- Large title
- Author
- Date
- Reading time
- Table of contents
- Content
- Related articles

---

## 13. Admin Dashboard

The admin interface should prioritize functionality.

**Sidebar:**
```
Dashboard
Resources
Projects
Products
Insights
Certificates
Settings
```

**Main area:**
- Statistics
- Recent activity
- Quick actions

---

## 14. Animations

**Use subtle animations:**
- Fade
- Slide
- Scale
- Hover
- Page transitions

**Avoid:**
- Excessive particles
- Constant motion
- Distracting 3D
- Heavy animations

Animations must not reduce performance.

Respect `prefers-reduced-motion`.

---

## 15. Responsive Design

**Breakpoints:**
- Mobile
- Tablet
- Desktop
- Large Desktop

Use mobile-first design.

Test every major page on mobile.

---

## 16. Accessibility

Ensure:
- Keyboard navigation
- Visible focus states
- Proper contrast ratios
- Semantic HTML
- Alt text on all images
- ARIA labels where required

---

## 17. Empty States

Every empty section should have a meaningful message.

**Example:**
> No resources found.

Add a useful action where possible.

---

## 18. Error States

Errors should be clear and human-readable.

**Example:**
> Something went wrong while loading this resource. Please try again.

Never show technical stack traces.

---

## 19. Loading States

**Use:**
- Skeleton loaders
- Progress indicators
- Spinners where appropriate

AI tools should display meaningful processing messages.

**Example:**
> Analyzing your document...

---

## 20. Brand Experience

The visitor journey should be:

```text
Discover AyushDevX
        ↓
Understand the Brand
        ↓
Explore Products
        ↓
Try AI Lab
        ↓
View Projects
        ↓
Explore Knowledge Hub
        ↓
Read Insights
        ↓
Contact AyushDevX
```

The interface should guide visitors naturally through this journey.

---

## 21. Design Principle

The website should feel:

> Professional enough for a technology company.
>
> Technical enough for developers.
>
> Simple enough for everyone.
>
> Innovative enough to represent AI.

Avoid generic portfolio design.
